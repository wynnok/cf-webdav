# ADR-0002: 备份可验证性 — 明文 MD5 作为 ETag

状态:已接受

WebDAV 的 `getetag` 当前返回 R2 密文对象的 etag,它随分块与 nonce 变化,客户端无法据此验证明文内容——`rclone check` 依赖 ETag 作校验和,会因此降级为仅大小比较。

决策:加密流在分块加密的同时计算**明文 MD5**,存入元数据,`getetag` 返回该明文 MD5(带引号)。明文校验与 GCM 认证分离:GCM 负责防篡改(恢复时的安全底线),明文 MD5 ETag 供客户端做内容级验证(rclone check / Duplicati verify)。完整性验证责任在客户端,本服务不提供服务端校验端点。

被拒绝:维持密文 etag(客户端无法验证);服务端全量校验 API(与「备份专用 + 客户端验证」定位不符,增加复杂度)。
