# ADR-0003: 运维与韧性模型

状态:已接受

备份服务的安全不止加密,还包括"数据不会因运维事故而丢"。本 ADR 记录部署边界与韧性决策:

- **部署**:Workers Paid(CPU 5min、subrequests 10k),使 PBKDF2 认证与 PROPFIND 逐文件 head 不撞限制。
- **R2 冗余**:单区域,不自建跨区复制;本服务是异地副本而非唯一副本(README 明示)。
- **R2 版本化**:不开启。WebDAV `DELETE`/覆盖写必须是真删,保持客户端保留策略的语义诚实;防误删/勒索依赖 GCM 完整性、账号记录导出与恢复演练,而非对象版本化。
- **锁**:存放在 KV 并接受其最终一致性(生产最多 ~60s);明确假设**备份任务不并发**(由客户端调度错开),不做强一致锁组件。
- **离线恢复包**:主密钥副本 + 定期导出的账号记录共同构成离线恢复包;任一丢失(MASTER_KEY 或 ACCOUNTS_KV 被删)都使数据不可恢复,故两者都要有离线副本。
- **配额**:不设服务端配额,成本靠 R2 面板与文档化估算管理。
- **认证迭代**:PBKDF2-SHA256 210k 次(可配置),靠 CF Rate Limiting 与强密码兜底暴力破解。
- **滥用防护与审计**:Cloudflare Rate Limiting(账号级配置) + Workers Logs 审计(方法/账号/路径),不在代码内自建。
- **管理面**:同一 Worker 在 `/admin` 提供服务端渲染的正式管理界面;只读浏览备份元数据,账号生命周期操作经同源 HTML 表单完成,不提供公开管理 API。
- **管理员认证**:管理员凭据以 `ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ADMIN_SESSION_SECRET` 三个 Worker Secret 配置。任一缺失时 `/admin` 返回 503。登录会话为浏览器关闭即失效、且最多四小时的签名 Cookie,写操作同时要求非跨站 Origin(同源、缺失或隐私模式/沙盒 iframe 的 `null`)与一次性 CSRF 令牌。部分浏览器、隐私扩展或代理会省略或屏蔽 Origin 头,故 Origin 检查只拦截携带跨站 Origin 的请求;实际防线是登录端点的管理员凭据校验、写操作的一次性 CSRF 令牌,以及 SameSite=Strict 会话 Cookie 使跨站或沙盒请求无法携带会话。
- **管理状态隔离**:管理员会话、CSRF 令牌和账号移除任务使用独立的 `ADMIN_KV`,不与账号记录或 WebDAV 锁共享;专用 `ADMIN_CSRF` Durable Object 原子消费一次性 CSRF 令牌,串行化账号移除与 WebDAV 写入,并领取每个调度窗口唯一移除批次。
- **账号移除**:危险移除先立即停用账号,再由每 15 分钟 Cron 在存在待处理索引时至多删除 500 个对象;空闲时不扫描移除任务。过程可暂停或继续但不可取消或回滚,完成后才删除账号记录。运行或暂停的移除任务禁止该账号启用、停用和密码重置。
- **账号移除故障与保留**:单个对象删除最多重试三次,仍失败则任务停止并保留失败对象和错误摘要。完成或失败任务的摘要、计数和错误信息保留 30 天,由 Cron 清理。

被拒绝:自建跨区复制 Worker、Durable Object 强一致锁、服务端配额索引、R2 版本化(理由如上)。
